## `> current_research`

### 🛰️ Climatology-Aware Quantum Channel (CAQC)

> A unified modeling framework for satellite-based QKD under realistic atmospheric conditions

```
  ┌─────────────────────────────────────────────────────────┐
  │                                                                   │
  │   ERA5 Reanalysis Climate Data  (ECMWF)                           │
  │   temperature · humidity · wind · aerosol optical depth profiles  │
  │        │                                                          │
  │        ▼                                                          │
  │   ┌──────────────────────────────────────────────┐        │
  │   │           Optical Propagation Engine                  │        │
  │   │   ├── Molecular Absorption  (Beer-Lambert law)       │        │
  │   │   ├── Mie / Rayleigh Scattering                      │        │
  │   │   ├── Turbulence-Induced Fading  (Cn² profiles)      │        │
  │   │   └── Time-Varying Stochastic Channel Representation │        │
  │   └────────────────────────────-─────────────────┘        │
  │        │                                                          │
  │        ▼                                                          │
  │   QKD Performance Layer                                           │
  │   ├── Quantum Bit Error Rate  (QBER)                              │
  │   ├── Secure Key Rate  (SKR)                                      │
  │   ├── Link Feasibility Windows                                    │
  │   └── Pass Visibility & Elevation Analysis                        │
  │                                                                   │
  └─────────────────────────────────────────────────────────┘
```

**Research Question:** How does atmospheric variability quantitatively degrade QKD link performance — and how can adaptive ML-assisted systems compensate?

**Approach:**
- Integrate ERA5 reanalysis datasets for time-varying channel parameterization
- Model elevation-dependent optical depth over Indian ground station sites
- Stochastic representation of turbulence across orbital passes
- Investigate ML-assisted RF–FSO switching for real-time link adaptation
- Validated against TLE-based satellite trajectory data

**[1] Design and Simulation of a Decoy-State BB84 Satellite QKD Constellation for Indian Ground Stations**  
📰 *Springer — International Journal of Information Technology* &nbsp;|&nbsp; **Q1 · Scopus-Indexed**  
👤 **First Author** &nbsp;|&nbsp; 📅 November 2025 &nbsp;|&nbsp; 🔗 [DOI: 10.1007/s41870-025-02860-y](https://doi.org/10.1007/s41870-025-02860-y)

<details>
<summary>Contributions & Scope</summary>

Designed synthetic Walker constellations and a realistic TLE-based orbital QKD simulation pipeline. Modeled Decoy-State BB84 over satellite-to-ground links with elevation-based filtering. Reported SKR, QBER, pass visibility, and link performance across five Indian high-altitude ground station sites.

**Key contributions:**
- First detailed QKD performance characterization over India-specific ground station geometry
- Elevation-based QBER modeling with atmospheric channel loss profiles
- Decoy-state protocol simulation with realistic noise floor assumptions
- Fully reproducible orbital mechanics pipeline using Walker + TLE data

</details>
